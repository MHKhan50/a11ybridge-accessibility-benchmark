# Data dictionary — `raw_results.csv`

One row represents one attempted browser task on one fixture variant. The CSV is generated by `run_experiment.py`; it is not a pre-existing empirical dataset.

| Column | Type | Definition |
|---|---|---|
| `run_id` | string | Unique UUID for this execution row. |
| `task_id` | string | Registered task identifier: `button_name`, `link_name`, or `textbox_name`. |
| `variant` | string | `baseline` (accessible-name/label baseline) or `defect` (controlled mutation). |
| `role` | string | ARIA role used by Playwright locator. |
| `expected_name` | string | Exact accessible name expected by the task policy. |
| `locator_count` | integer | Number of elements matched before action; zero indicates no match. |
| `success` | boolean | True only when exactly one locator matched, the action ran, and completion marker became visible. |
| `exception_type` | string | Exception class if execution failed; empty on success. |
| `exception_message` | string | Truncated exception message; empty on success. |
| `duration_ms` | float | Time from immediately before locator/action handling through completion or caught failure, in milliseconds. Not a standardized performance measure. |
| `python_version` | string | Python runtime version. |
| `platform` | string | Runtime platform description. |

## Missingness and interpretation

Exception fields are empty for successful rows. `locator_count` is recorded even if it is zero or greater than one. `success` is an execution outcome for this benchmark's deterministic policy, not a human accessibility outcome. Timing is sensitive to machine load and browser/runtime versions.
